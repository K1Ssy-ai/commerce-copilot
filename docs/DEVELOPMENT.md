## 当前验证范围

本版本仅包含文档和 SVG，不运行参考项目，不要求配置模型密钥或安装其依赖。交付检查应包括：

- 本地 Markdown 文件链接能解析到存在的文件。
- SVG 可以被浏览器渲染，标题和图形没有溢出。
- README 对已完成、规划中和授权待确认的描述一致。
- 没有 `.env`、真实客户数据或密钥进入待提交文件。

没有应用测试通过或线上部署成功的声明；功能代码加入后再增加对应验证。

## 提交约定

```powershell
git status --short
git diff --check
git diff
```

只暂存当前任务相关文件。提交邮箱须来自已经验证的 K1Ssy-ai 账号信息；不猜测邮箱、不借用上游作者身份、不修改全局 Git 身份。

首次推送前，确认远端确实属于 `K1Ssy-ai`。使用默认分支承载已验证的新增工作；遇到已有内容先读取并整合，不强制推送覆盖。

## 每日工作节奏

1. 查看当前阶段、用户最新要求和实际仓库状态。
2. 从 ROADMAP 选择一个未完成且已授权的任务，明确验收标准。
3. 完成实际改动，并执行与改动相称的验证。
4. 验证通过后记录变更并提交；有权限时推送到自己的仓库。
5. 若许可、登录或阶段授权受阻，保留已完成成果并说明所需操作，不制造占位提交。

每日任务执行依赖可用的网络、GitHub 登录和运行环境，无法承诺每天必定显示贡献。用户尚未启动功能阶段时，不自动扩张到完整电商系统开发。
